# AGENTS.md

## Project Type

This project is a plain HTML + CSS static SaaS landing page.

It is a Codex training project. The goal is to practice directing Codex through small engineering tasks, not to build complex product functionality.

## Technical Constraints

- Use plain HTML and CSS only.
- Do not add JavaScript.
- Do not use npm.
- Do not add external dependencies.
- Do not use frameworks such as React, Vue, Tailwind, Bootstrap, or similar tools.

## Working Rules

- Inspect relevant files before making any change.
- If the task is not a read-only review, provide a short plan before modifying files.
- Keep each change small, safe, and easy to review.
- Do not introduce unrelated experiments, refactors, tools, assets, or dependencies.
- Modify only the files required by the current task.
- Before finishing, confirm that no extra files or folders were created.

## Completion Report

After each non-read-only task, report:

- Changed files.
- Manual verification steps.
- Known limitations.
- Confirmation that no extra files or folders were created.

## Response Language

Use Chinese for explanations, while preserving technical terms, file names, commands, and code symbols such as `index.html`, `styles.css`, `AGENTS.md`, `:focus-visible`, and `Get-ChildItem`.
